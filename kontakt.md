# Kontakt

Für Fragen, Fehlerhinweise oder redaktionelle Anmerkungen nutzen Sie bitte das folgende Formular oder schreiben Sie direkt an redaktion@cfd-bonus-ratgeber.de.

## Für Korrekturen

Fehler in unseren Inhalten können Sie direkt über das Formular melden. Bitte geben Sie die betroffene Seite, die fehlerhafte Angabe und die korrekte Quelle an. Bestätigte Korrekturen werden innerhalb von 5 Werktagen umgesetzt.

## Datenschutz

Ihre Anfrage wird ausschließlich zur Bearbeitung Ihres Anliegens verwendet. [Datenschutzerklärung](/datenschutz)
